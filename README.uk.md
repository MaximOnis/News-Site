# News-Site

Вебзастосунок для перегляду та фільтрації новин за тематичними категоріями. Проєкт розроблений у межах навчальної курсової роботи з вебтехнологій.

## Можливості

- Перегляд загального списку новин.
- Перегляд новин за категоріями: спорт, бізнес, культура, економіка, політика та наука.
- Фільтрація новин за датою публікації.
- Перегляд повного тексту окремої новини.
- Зберігання інформації про новини в базі даних SQLite.

## Технології

- Python — основна мова програмування.
- Flask — розробка серверної частини вебзастосунку.
- SQLAlchemy — взаємодія з базою даних.
- SQLite — зберігання даних.
- HTML/CSS — створення та оформлення вебсторінок.

## Структура проєкту

- app.py — основна логіка вебзастосунку та маршрутизація.
- model.py — модель даних і налаштування підключення до бази даних.
- templates/ — HTML-шаблони сторінок.
- static/ — статичні файли та ресурси.
- tests/ — файли тестування.
- BaseNews.db — база даних новин.
- requirements.txt — список залежностей проєкту.

## Призначення

Проєкт створений з навчальною метою та демонструє розробку вебзастосунку на Flask, роботу з базою даних SQLite, використання ORM і реалізацію фільтрації та відображення інформації.
