# News-Site

A web application for viewing and filtering news by topic. This project was developed as part of a course assignment on web technologies.

## Features

- View a general list of news articles.
- View news articles by category: sports, business, culture, economy, politics, and science.
- Filter news articles by publication date.
- View the full text of a specific news article.
- Store news information in an SQLite database.

## Technologies

- Python — primary programming language.
- Flask — development of the web application’s server-side.
- SQLAlchemy — database interaction.
- SQLite — data storage.
- HTML/CSS — creation and styling of web pages.

## Project Structure

- app.py — main web application logic and routing.
- model.py — data model and database connection settings.
- templates/ — HTML page templates.
- static/ — static files and resources.
- tests/ — testing files.
- BaseNews.db — news database.
- requirements.txt — list of project dependencies.

## Purpose

This project was created for educational purposes and demonstrates how to develop a web application using Flask, work with an SQLite database, use an ORM, and implement filtering and data display.
